# RallyBoard
Mobile-first Volleyball Matchday Tracker für SG Kaarst.

## Stand
Statische Webapp für Netlify, direkt ohne Build deploybar. Spieltage, Kader, Zuspiele, Spieleraktionen, Auswechslungen, Satzstände, MVP-Ranking und JSON-Backup. Lokale Speicherung via localStorage. Kein Supabase-Sync und kein verlässlicher Offline-PWA-Cache in dieser Version; Cloud-Integration folgt nach separater Supabase-Einrichtung. Keine historischen Spieldaten vorimportiert.

## Deployment
Netlify mit GitHub-Repo verbinden, Publish Directory: Repository-Root. Keine Build Command nötig.

## Datenschutz
Das Repository ist aktuell öffentlich. Keine Zugangsdaten oder Supabase Service-Role-Keys einchecken.

GitHub Pages deployment refresh: 2026-11-14.
